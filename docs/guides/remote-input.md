# 用手机给电脑输入文字

在电脑的 OpenLess 设置中开启远程输入。让手机和电脑连到同一可信网络，用手机浏览器打开电脑显示的地址。浏览器使用麦克风前，需要先信任这台电脑的证书。

## 第一次连接

1. 在电脑本地设置找到「本机根证书 SHA-256」。这是根证书的指纹，共 64 个十六进制字符。
2. 用手机打开电脑显示的地址，下载适合手机的证书。首次出现浏览器警告时，优先通过可信文件传输渠道取得证书。
3. 在手机**系统证书详情**里核对根证书的全部 64 个字符。可以忽略空格、冒号和大小写。指纹看不全或不一致时停止安装。网页显示的文字、证书名称和配对码都不能替代这一步。

**iPhone / iPad**　在「设置 → 通用 → VPN 与设备管理」打开描述文件，确认只包含一张根证书。若系统只能在安装后显示完整指纹，先保持「完全信任」关闭，核对成功后再到「通用 → 关于本机 → 证书信任设置」开启。无法独立核对时移除描述文件。[Apple 证书信任说明](https://support.apple.com/zh-cn/102390)

**Android**　下载 CA 证书，在系统预览中核对后再安装。部分系统在安装时立即信任该证书。如果系统无法先显示完整指纹，请通过已有的可信文件传输渠道取得并核验，或停止安装。

信任完成后刷新手机页面，输入电脑显示的配对码，并允许浏览器访问麦克风。不再使用时，可以从手机移除这张根证书。

## 开始听写

在手机上开始录音。开启「电脑落字」时，电脑会把文字送到当前可用的输入位置；也可以关闭它，只在手机上查看结果。

手机页面默认在录音时尝试保持亮屏。锁屏、切到后台或网络中断后，电脑会尝试处理已经收到的音频。回到页面重新配对或认证后，可以找回结果。仍找不到时，请打开电脑上的历史记录。主动取消、关闭远程输入或重置配对码会使旧会话失效。

重装电脑应用时，保留该电脑自己的应用数据可以保留证书信任。清空应用数据后，请在手机移除旧证书，再按上述流程核对新证书。[证书与会话技术说明](../development/remote-input.md)
