## 2. 平台特有门槛

- **Windows**：TSF/IME 管线（`windows-ime/` 工程；`scripts/windows-ime-*.ps1`、`scripts/windows-package-msvc.*`）；Foundry/Sherpa 本地 ASR；`scripts/windows-*-smoke.ps1` 套件在真机执行。
- **macOS**：AX/TIS 授权流、Apple Speech、MLX（`scripts/macos-mlx-*.mjs`、`scripts/macos-capsule-spaces-contract.test.mjs`）、签名与公证（`scripts/build-mac.sh`、release workflow）。
- **Android**：APK 工作流（`.github/workflows/android-apk.yml`）+ 悬浮窗/无障碍/Shizuku 契约（`scripts/android-*.test.mjs`）。

## 3. 完成口径

安装包、签名、公证与最终 head CI 证据分别记录；未执行项不得改写为通过。设备/安装/升级/回滚验收是发布门，不属于本清单可由代码自证的部分。
