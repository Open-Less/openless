本仓库的 [JSON 引用说明](agent-app-model-catalog.json) 只指向外部目录，避免复制维护。服务端本机 checkout 为 `/Users/lvbaiqing/orca/workspaces/openless-marketplace/app-catalog-api`。接口契约见该仓库 `docs/app-catalog-api.md`；此研究文档不是已部署 API 的声明。

## 先区分六个概念

| 概念 | 含义 | 例子与识别后果 |
| --- | --- | --- |
| 产品/品牌 | 用户购买或使用的服务名称，可同时提供多种形态 | ChatGPT、Claude、DeepSeek、Qwen；品牌本身没有统一的 OS 应用身份 |
| 客户端/前台应用 | 实际接收听写输入的桌面程序或独立安装式 Web App | Orca、Cursor、DeepSeek Harness；识别 bundle ID、EXE stem 或已证实的 Web App 模式 |
| 模型提供方/模型族 | 提供推理能力的机构与模型系列 | OpenAI/GPT、Anthropic/Claude、Google/Gemini、DeepSeek V/R1；与承载它的客户端是多对多关系 |
| API 模型标识 | 请求接口时使用的 model 字符串 | `gpt-6.1-sol`、`deepseek-flash`；不是 bundle ID、进程名或前台应用 |
| Agent Harness | 把模型、工具、执行循环、状态与权限接成可持续工作的执行层 | Claude Code、Codex CLI、DeepSeek Harness、goose、OpenClaw、Deep Agents；可能有桌面/CLI/SDK，并非都能独立识别为应用 |
| IDE 扩展/SDK/编排运行时 | 运行在宿主内的组件或开发基础设施 | Copilot/Cline/Roo/Continue 在 VS Code；Claude Agent SDK/Codex SDK；LangGraph 是编排运行时，Deep Agents 才是对应 harness |

`category` 只表达输入用途；`role`/`roles` 表达软件角色。因此 Harness 可用 `role=agent_harness` 查询，无需添加第七个输出风格类别。常见 AI 助手和 agent 前端按本项目要求放入 `coding`，这不是声称用户在这些应用中只能写代码。当前模型与任务由会话决定，不能由前台应用推断。

## 分类、提示词与独立 API

| category | 名称 | promptGuidance 的范围 |
| --- | --- | --- |
| `coding` | 编程与 AI | 辅助辨识代码、API、文件路径、仓库、分支、编程 agent、工具调用、模型与任务指令。AI 客户端也归此输入用途；不得据应用推断所选模型。用户选择的风格、任务和输出规则优先。 |
| `chat` | 聊天 | 辅助辨识人与群组、对话对象、称呼、即时消息中的短句与协作术语；用户选择的风格和输出规则优先。 |
| `email` | 邮件 | 辅助辨识收件人、主题、正文、称呼、附件与邮件往来语境；不自行补写主题或署名，用户选择的风格和输出规则优先。 |
| `writing` | 写作与笔记 | 辅助辨识笔记、草稿、段落、来源、标题和引用对象；是否分段、扩写、总结由用户所选风格和任务决定。 |
| `office` | 办公 | 辅助辨识文档、表格、单元格、公式、图表、演示文稿与业务数据术语；不得擅自推算或补写数据，用户选择的风格和输出规则优先。 |
| `browser` | 浏览器 | 辅助辨识网页、网址、搜索、表单与导航术语；普通标签页属于浏览器，不根据标题猜测网站、模型或任务。用户选择的风格和输出规则优先。 |

目录服务提供：

- `GET /v1/app-catalog`：完整原始目录。
- `GET /v1/app-catalog/categories`：六类及其辅助术语提示。
- `GET /v1/app-catalog/clients?category=coding&role=agent_harness&provider=deepseek&platform=macos`：客户端查询，筛选条件同时生效。
- `GET /v1/app-catalog/clients/:id`：单客户端。
- `GET /v1/app-catalog/model-families?provider=openai` 及 `/model-families/:id`：模型族查询。

客户端 `provider` 筛选对应 `providerIds`，即已核实关联模型族的提供方集合，不等于产品发布者 `publisher`，也不等于当前选中模型。`role` 匹配主角色或 `roles` 中的附加角色。`platform=web` 表示网页形态；platforms 同时包含已核实产品平台与为保留旧规则而加入的识别平台。后者在 platformEvidence 标为 legacy_recognition_only，不是厂商当前发行支持；空 platforms 表示没有充分证据列出系统矩阵。ID 为稳定机器值，名称与别名可随官方更名更新。每个条目的 `promptGuidance` 仅辅助识别工具、对象和术语，用户风格包及其输出规则优先。

## DeepSeek 的核验结论

**官方现在确实有 macOS / Windows 桌面产品，名称是 DeepSeek Harness。** 官网首页直接链接 Harness 与应用下载，官方下载页列 Apple Silicon macOS 13+ 和 Windows 64 位，Harness 页还链接 DeepSeek 自己的开源仓库；不是第三方包装器。官方消费助手的网页/iOS/Android 与 Harness 桌面产品在目录中分成两个条目。[deepseek-home] [deepseek-download] [deepseek-harness] [deepseek-readme]

本机 `/Applications/DeepSeek Harness.app/Contents/Info.plist` 实读版本 `0.2.2-rc.5`，`CFBundleIdentifier=com.deepseek.dsh`。Windows 官方提供 `dsh-latest-windows-x64.exe` **安装器**，它不能证明安装后运行进程名称，因此 `windowsExecutableStems` 保持空数组。没有下载、安装或运行第三方 DeepSeek 客户端。[installed-deepseek]

当前官方 API 使用 `deepseek-flash` / `deepseek-v4-pro`；Flash 别名映射与旧型号退休说明来自实时官方文档，不根据本机日期推算版本。API 不具有独立前台 app 身份。[deepseek-api] [deepseek-pricing]

## 身份与形态的维护规则

- 目录现有 77 个条目提供 macOS 精确身份、54 个条目提供 Windows stem；其中 26 个 macOS 条目和 Cherry Studio 的 Windows stem 来自首轮厂商/安装元数据核实，其余或同时存在的兼容值逐项标在 compatibilityEvidence。不能把迁入的旧值称作本轮重新核实。
- 从 OpenLess 官方仓库旧提交 `98477f0b420cea2f88359c3214707f42af0ad8fa` 的 `InputApp::category` 精确迁入 71 个 macOS Bundle ID、59 个 Windows stems，以及 5 个名称 × 3 个前缀的 15 个 Web App 组合；全部仍归旧分类，不因移出 Rust 而丢失匹配。[openless-98477f0b-compatibility]
- 旧规则覆盖编程工具、终端、Docker、聊天/会议、邮件、写作笔记、Office 和浏览器。已有研究条目按同一客户端合并标识/alias，未另建重复应用；Mac/Windows 匹配忽略大小写，因此不重复放入只差大小写的值。ChatGPT/Codex 共用身份仍按 canonicalClientId 去重。
- 来源分两级：厂商源代码、构建配置、当前 Homebrew cask、实际已安装 app 元数据是本轮识别核验；OpenLess 旧规则是明确保留的兼容证据。既无本轮证据也未在旧规则出现的新身份继续留空。安装器名、CLI 命令和 macOS 可执行文件名均不能推导新 Windows stem。
- 普通浏览器标签页按 browser。安装式 Web App 必须同时匹配前缀和完整名称；9 个研究条目仍有 Chrome 模式。Gemini/Google Gemini、ChatGPT、Claude、Google AI Studio 另恢复旧规则中的 Edge `com.microsoft.edgemac.app.` 和 Safari `com.apple.safari.webapp.` 前缀，只恢复这些旧名称的既有组合，不扩展到其他品牌。Chrome 前缀另有 Chromium 与 cask 核验，Safari/Edge 本次只作为迁移兼容证据。[chromium-webapp] [chrome-cask] [openless-98477f0b-compatibility]
- ChatGPT 当前本机及 cask 是 `com.openai.codex`；旧 `com.openai.chat` 也作为兼容身份保留。Codex 历史条目仍指向 ChatGPT，不应重复生成两个同身份的当前应用行。[chatgpt] [cask-chatgpt] [installed-chatgpt] [openless-98477f0b-compatibility]
- 原生 Google Gemini 的已核实 bundle 是 `com.google.GeminiMacOS`，与 MacPaw Gemini 文件清理产品不同。DeepSeek Harness 保留本机核实身份，新 Windows stem 仍为空，因为旧规则没有它。[gemini-desktop-current] [google-gemini-cask] [installed-deepseek]
- Superset/Paradev、Conductor 等保留旧 Windows stem 是为了维持已有分类，不等于推翻本轮官网的当前平台说明。仅因迁移新增的平台列于 platformEvidence；产品生命周期与官方支持限制继续保留。Windsurf、Warp 的旧标识同样按兼容证据保留，不冒称重新验证。[superset] [windsurf] [openless-98477f0b-compatibility]
