## 实验实现与待验证门禁

只改变 Windows event-loop target 的所有权：固定 runtime-wry 2.12.2，本地 path patch 同时覆盖直接与传递依赖；owner TLS 保存 target，跨线程 handle 只复制原子元数据。owner 注销后 handle 不再取得 target，在飞 callback 的本地 Rc 使 payload 活至返回；真实 target 的访问、Rc traffic 与析构留在 owner。非 Windows 行为保留，不套用 WASAPI、DSP 或 HWND 补丁。

P1–P6、单日志、parent/thread 标签和独立 health 保留。P2 仅增加真实 handle clone 前后的闭合事件，使 dump 中发生于 app() 克隆、早于旧 requested 的失败边界可观察；不扫描全应用 clone，不新增 probe 类别。attempt/change 改为 A1/C1，准确 build_id 区分产物。

Actions 门禁包括生产 helper 的确定性测试和编译拒绝测试、准确 patched graph metadata 校验、无 ASR/WebView 的真实 Windows runtime clone/drop、iteration/consuming-return/run 生命周期进程测试，以及原有全 CI、桌面和 Android。未执行的门禁不记作通过；完整 Windows Tauri --no-run 只算编译覆盖。

当前尚无 A1 现场复测，不能判 EFFECTIVE。CI 通过后以准确 SHA 的已验证 Windows 包按相同 N0–N6 复测：空闲覆盖此前约 7 小时 24 分钟，活动负载保持可比较，分别记录崩溃、UI 假死、进程状态和实际插入效果。无异常日志不等于成功；复现失败需该 SHA 匹配符号的受控 dump，不能混用旧 60155b00 转储。未经用户确认不删探针或日志。
