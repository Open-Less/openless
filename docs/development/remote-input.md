# 远程输入：证书、会话与录音恢复

用户设置见[手机远程输入](../guides/remote-input.md)。Tauri 的 `remote_server` 与 Linux 的 `remote_input.rs` 分别负责监听器、HTTPS 和 WebSocket 入口，共用 Core 的远程输入及外部录音会话。

## 证书

- 首次使用时，宿主生成并原子保存本机独立的根证书和服务器证书。页面下载的是公开根证书或含该根证书的 iOS 描述文件。设置里的完整 SHA-256 来自实际运行的监听器。
- IP 变化和服务器证书续期复用同一根证书。服务启动时会检查证书剩余时间，少于 30 天重新签发服务器证书。根证书损坏、将到期或密钥不匹配时停止启动，等待显式恢复。
- `remote-tls-identity-v1.json` 包含私钥，跟随本机应用数据保留。仅从同一台电脑的备份恢复。旧版自签名服务器证书无法作为新根证书复用。
- 自动验证用真实 rustls 握手覆盖不同电脑、IP 变化、续期、坏密钥和持久化失败。用户设备的指纹可见性单独实测。

## 录音和恢复

浏览器仅在前台录音期间尝试保持亮屏。失去麦克风、进入后台或断线时，宿主收尾已收到的音频；连续 15 秒没有有效音频也会结束采集。识别开始后，普通断线不撤销桌面结果和历史写入。主动取消、关闭远程输入或重置配对码会撤销会话。

已收到的音频按现有设置保留为 WAV，失败时可用于历史重新转写。成功后的留存由用户设置决定。手机恢复查询需要有效配对和单独的随机恢复凭据。服务保留最近 64 个会话的恢复权限，最长 24 小时；重启、撤销或重置配对码后失效。

cargo test --manifest-path openless-all/app/src-tauri/backend-tests/Cargo.toml --test remote_tls
