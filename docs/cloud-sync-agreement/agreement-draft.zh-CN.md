## 3. 加密、密码与设备安全

客户端使用 Argon2id 从同步密码在本机派生密钥，再以 XChaCha20-Poly1305 对快照进行认证加密，通过 HTTPS 传输密文及协议所需信息。在此同步流程中，同步服务器接收加密后的 API 密钥及其他快照内容，不接收 API 密钥明文、同步密码或派生解密密钥。该设计将快照的解密能力保留在客户端；安全仍取决于密码强度、设备与软件安全、实现正确性和实际运维，弱密码、设备失陷或实现漏洞可能导致数据泄露。[F05、F06]

密码在本机按 Unicode NFC 规范化，保留大小写和空格差异；当前要求规范化后 12–128 个字符并含 ASCII 大写、小写和数字，创建及改密另有常见弱密码等检查。满足这些检查的密码仍可能被猜中，请使用独有且难以猜测的密码并可靠保存。[F05]

“记住密钥”将解锁密钥交由本设备的系统安全存储管理，并绑定服务地址、账号、vault、key 和设备。同步密码留在客户端，自动解锁依赖该设备保存的密钥。已授权本机使用的人或控制本机的恶意程序仍可能接触解锁后的数据；系统安全存储被拒绝、丢失或损坏可能阻止自动解锁或本地恢复。[F07]

**服务提供者不能找回原同步密码，也没有绕过加密重置密码以解开原备份的接口。** 当前改密操作仍要求当前密码。已解锁设备可能保有可取回的本地资料，但不能据此承诺无旧密码改密或恢复原密码。若密码遗失且没有可取得资料的本地副本，云端内容可能永久无法读取；重新创建备份也不会解开旧密文。[F05、F07、F10]

端到端加密保护同步链路中的快照内容及云端快照内容。本机运行和恢复后，应用仍需读取本机资料及服务凭据，并在内存中处理相应明文；本机资料按各自存储方式保存。请保护设备、操作系统账号和 GitHub 账号。[F03、F07、F09]

## 5. 同步、恢复、冲突与结果未知

自动同步需要已启用、认证可用且设备已解锁。当前客户端按启动及本机持久化变更触发同步，并非持续轮询所有设备；网络、代理、服务限额、账号失效或本机忙碌都可能延后同步。请检查当前状态，不能仅凭点击按钮或开关已打开认定数据已经上传。[F11]

首次使用已有云端快照时，客户端须先验证并展示恢复预览，由您确认替换或合并；可合并的日常远端变更也可能在自动同步中应用到本机。需要选择的冲突会暂停并要求复查。替换会改变本机登记资料，合并也可能改变渠道选择、凭据或历史；请在重要恢复前保留您需要的独立副本。[F09、F11]

恢复过程会校验云端版本、本机数据代次及账号与密钥范围，并使用本机加密恢复日志、写入隔离和运行态效果确认。恢复失败可能回滚；回滚也无法完成时会进入需要恢复的状态。恢复不授予操作系统权限，不执行其他设备路径或自动启动 Agent。不要将软件保护机制表述为恢复永不失败。[F09]

上传、改密或删除的请求可能已被服务端处理，但客户端没有收到响应。“结果未知”表示客户端尚待核实该操作是否提交及其最终结果；应先核对原操作，避免重复创建或用默认值覆盖。已经提交的请求仍可能在取消或关闭后完成；恢复进入持久化事务后仍需完成提交或回滚。[F09、F12]

## 6. 关闭、锁定、退出与删除

关闭同步用于停止该设备继续自动同步，保留本机资料和云端快照；锁定用于停止本设备解锁并尝试清理记住的密钥。退出登录会停用同步并清理相应本机认证或解锁材料，远端注销在离线时可能无法立即完成。上述操作后云端快照继续保留；删除云端资料须另行执行下一段的删除流程，已经发出的操作仍需结算其结果。[F07、F12、F13]

删除云端备份需要单独明确确认，并绑定所见 vault 和版本。成功确认后当前云端快照不再可供恢复，本机资料保留；其他设备获知删除状态后不会自动重建该快照，但离线设备的本机副本不会被远程擦除。用户日后主动创建新备份是另一项操作。[F12、F13]

**7 天的含义与边界：** 2026-11-18 无凭据读取官方能力接口时，其声明服务备份副本最多保留 7 天；旧客户端文档也记录过 7 天。这是公开能力声明的核对结果，尚未核实实际备份清理、复制和灾难恢复操作。正式条款应在运营核实后承诺并解释该上限、起算点及例外；当前草案不把接口声明视为已完成物理删除的证据。[F14]

删除仍会留下用于阻止旧设备复活快照的版本及删除状态等控制资料。单条文档删除标记在当前加密同步格式中也会保留，当前版本未做其自动回收；它与整个云端快照的删除分别处理。元数据、认证日志、操作收据和依法保留资料的期限及处理方式另为 **[待确认]**。7 天上限仅涉及该能力声明中的服务备份副本；当前用户恢复流程读取当前快照，历史版本选择能力须另行确认。[F12、F14、F15]
