# OpenLess 加密云同步：用户摘要（审查草案）

> **未生效、未完成法律审查，仅供审阅。** 本摘要依赖 [协议草案](agreement-draft.zh-CN.md)，事实核对日期为 2026-11-18，正式生效日期待定。开发版的 `encrypted-full-snapshot-v2` 用于记录本机范围告知确认。主体真实姓名、联系与隐私渠道、适用法律仍须确认。

- **免费、可选择。** 服务由 OpenLess 个人开发者提供，开发者及赞助商免费支持，面向全球用户；用户确认服务器赞助商为 Mivra 品牌。赞助商实际法律实体、部署地区和访问权限仍待确认。同步本身不收费，您自行使用的网络和第三方服务可能另行收费。[U1、W1]
- **启用后将上传已登记的 API 密钥（在客户端加密后作为密文上传）和私密文本历史。** 登记范围还包括偏好、服务渠道配置、词典及词汇预设、纠正规则、风格内容和图标、每日活动统计以及设备档案。当前按登记范围整体同步；如果希望排除 API 密钥或历史，请保持同步关闭。[F03、F05]
- **云同步服务只保存和传递含服务密钥的加密快照。** OpenLess 云同步服务不使用您登记的服务 API 密钥调用模型、转写或其他服务。OpenLess 客户端在执行您发起的服务请求时，使用相应凭据向您配置的服务端点认证。[F03、F05、F06、F16]
- **录音本体不上传。** 同步密码和密钥、OpenLess 管理的 OAuth 登录态及令牌、设备私钥、系统权限、模型和缓存等也不进入快照。设备路径保存在密文档案中，不会在另一设备作为程序执行。[F03、F04、F09]
- **本机加密，单独处理同步认证和元数据。** 客户端用 Argon2id 从同步密码派生密钥，用 XChaCha20-Poly1305 认证加密，再经 HTTPS 上传。同步服务器接收密文及账号、版本、大小、时间等必要协议资料，不接收 API 密钥明文、同步密码或派生解密密钥。GitHub 访问令牌单独发送以换取同步会话。部署、日志和跨境细节须补齐正式告知。[F05、F06、F08]
- **密码无法找回。** “记住密钥”依赖本设备系统安全存储。改密需要当前密码，已解锁时也适用。密码遗失后，若无法从本地副本取得资料，云端内容可能永久无法读取。[F05、F07、F10]
- **请以同步操作的完成状态为准。** 自动同步需要启用、登录和解锁；首次接入已有云端资料须先确认恢复，可合并的日常变更也可能自动应用。冲突需复查，“结果未知”需先核对原请求。已到达服务器的操作仍可能在取消后完成。[F02、F09、F11、F12]
- **关闭、退出与删除不同。** 关闭、锁定或退出不删除云端快照；单独确认删除才删除当前云端备份，本机副本保留，离线设备不会被远程擦除。[F13]
- **7 天的声明只适用于服务备份副本。** 2026-11-18 官方公开能力接口声明备份副本保留上限为 7 天，实际清理机制仍需运营核实。删除标记、操作收据、账号和日志的用途与期限须另行说明。当前恢复流程读取当前快照。[F14、F15]
- **双方都有责任。** 请保护密码、设备和账号；弱密码、设备失陷或软件漏洞仍可能导致资料泄露。开发者应采取合理安全措施、及时处理漏洞与事件，并在免费和赞助模式下继续履行适用法律规定的责任。安全、隐私请求及服务终止前的数据取回渠道仍须落实。[拟议条款，见正文第 7–10 条]
