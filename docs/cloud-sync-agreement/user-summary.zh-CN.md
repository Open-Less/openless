# OpenLess 加密云同步：用户摘要（审查草案）

> **未生效、未完成法律审查，不用于替换应用现有正式告知。** 本摘要依赖 [协议草案](agreement-draft.zh-CN.md)，事实核对日期 2026-11-18，不是生效日期。没有新建或变更 `consentVersion`。主体真实姓名、联系与隐私渠道、适用法律仍须确认。

- **免费、可选择。** 服务由 OpenLess 个人开发者提供，开发者及赞助商免费支持，面向全球用户；用户确认服务器赞助商为 Mivra 品牌。赞助商实际法律实体、部署地区和访问权限仍待确认。同步本身不收费，您自行使用的网络和第三方服务可能另行收费。[U1、W1]
- **会同步 API Key 和文本历史。** 登记范围包括偏好、服务渠道和凭据、词典及词汇预设、纠正规则、风格内容和图标、文本历史、每日活动统计以及设备档案。当前不是逐类勾选备份：如果不希望 API Key 或历史进入加密快照，请先不要开启。[F03]
- **录音本体不上传。** 同步密码和密钥、OpenLess 管理的 OAuth 登录态及令牌、设备私钥、系统权限、模型和缓存等也不进入快照。设备路径保存在密文档案中，不会在另一设备作为程序执行。[F03、F04、F09]
- **本机加密后传输，但元数据与认证仍需处理。** 服务器接收密文及账号、版本、大小、时间等必要协议资料；GitHub 登录令牌单独用于同步认证。备份不含令牌，不代表认证令牌从不发送。部署、日志和跨境细节须补齐正式告知。[F05、F06、F08]
- **密码无法找回。** 密码及派生密钥不发给同步服务器；“记住密钥”依赖本设备系统安全存储。当前改密仍要求旧密码，已解锁设备不构成无旧密码重置承诺。若没有密码也没有可取得的本地资料，云端内容可能永久无法读取。[F05、F07、F10]
- **开关打开不代表同步完成。** 自动同步需要启用、登录和解锁；首次接入已有云端资料须先确认恢复，可合并的日常变更也可能自动应用。冲突需复查，“结果未知”需先核对原请求。取消不能撤回已到达服务器的操作。[F02、F09、F11、F12]
- **关闭、退出与删除不同。** 关闭、锁定或退出不删除云端快照；单独确认删除才删除当前云端备份，本机副本保留，离线设备不会被远程擦除。[F13]
- **7 天不是所有资料同时归零。** 2026-11-18 官方公开能力接口声明备份副本保留上限为 7 天，实际清理机制仍需运营核实。删除标记、操作收据、账号和日志有不同用途与期限，须单独说明；这也不承诺可恢复任意历史版本。[F14、F15]
- **双方都有责任。** 请保护密码、设备和账号；开发者应采取合理安全措施、及时处理漏洞与事件，并按适用法律承担责任。免费不代表全免责，加密也不保证绝对安全。安全、隐私请求及服务终止前的数据取回渠道仍须落实。[拟议条款，见正文第 7–10 条]
