# React 前端重构：任务与交接

| 任务 | 所有权 | 完成/验收 |
|---|---|---|
| T0 基线 | QA 夹具、对照矩阵 | 复跑失败；同构建浏览器与安装版，记录 WebView、内容区、DPI、缩放、数据，观察 DOM/原生/命中 |
| T1 启动、API 和预览 | app/runtime/api/data/preferences/preview（启动路由与构建由集成负责人独占） | 平台能力/键位一致；原生握手、重建、引导、静默启动；预览事件与模拟写 |
| T2 共享 UI | ui/layout/overlays/controls/styles/motion、主窗/设置浮层约定 | Portal 边界、确认取消、Escape、栈、卸载结算和焦点还原；主题、三档缩放、动画/降动效 |
| T3 原生辅助窗口 | runtime/windows 与胶囊、QA、语音编辑、选区、失败卡 | 快速开闭/会话替换、跨屏 DPI、实际内容区/命中、穿透、Android 返回 |
| T4 历史 | api/history、data/history/usage、概览/历史/随手记/用量、preview/store | 两次提交连续事件、旧请求、清空/随手记/累计活动、后台更新、一次反馈、录音中拒绝、年度应用统计 |
| T5 领域拆分 | 设置/渠道/同步/本地 ASR、风格/市集、词库/纠错/翻译、更新与引导 | 按域接 API，草稿、权限、下载/更新、恢复、失败路径，归并组件和样式 |
| T6 集成清理与独立验收 | 构建、导入/资源路径、模块索引、契约和回归 | npm test、格式、Chromium/WebKit、原生窗口及 APK/HAP 验证；失败退回文件负责人再复测 |

顺序：T0；T1 和 T2 公共接口对齐，随后按互斥领域并行推进 T3/T4/T5；最后 T6。共享文件唯一负责人，移动方包含文件的旧、新路径。接口和路径变更先同步消费者。主 Agent 协调；实现、集成、独立验收均显式派发 GPT-6.1 / high。当前 Dev-1 是取证基线，最新远端 beta 是实施基线，独立未合功能先走各自的 PR；从専枝推送、开 PR、结束并核查各必需 CI，缺少真机或已有宿主缺口按平台和场景列出。
