# OpenLess 客户端图表

这组图表描述当前 `beta` 客户端的界面、Tauri 宿主、`openless-core`、外部服务，以及启动、权限和录音交接。每张图保留三种形式：

- `.mmd`：可编辑的 Mermaid 源文件。
- `.svg`：可缩放的矢量图。
- `.png`：适合在 README 和代码托管页面中直接查看的渲染图。
