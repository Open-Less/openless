## Linux

- **补齐选区语音流程。** 从热键、选区、录音和意图分流接到问答或编辑预览。验证确认、取消与应用失败的处理，并阻止迟到结果写到新会话。源码入口为 [Linux 热键和运行时](../openless-all/app/linux-egui/src/) 与 Core 的选区语音服务。
- **补齐真实桌面和安装证据。** 分别在 X11 与 Wayland 检查 Fcitx5 注册、目标应用落字、选区、权限、录音设备切换、静音恢复、托盘重开及系统凭据。用对应的 deb/rpm 候选验证安装、升级、回滚、卸载和校验和。在证据齐备前继续本地打包。见 [Linux 宿主接口](development/linux.md)及[发布规范](../RELEASING.zh.md)。
- **验证 Linux 手机远程输入。** 用真实手机检查连接、证书、配对、录音、仅转写、落字、断线恢复，以及关闭服务后权限撤销。记录手机系统、浏览器与 Linux 桌面组合。

## 感知、表达学习与服务用量

## 加密云同步正式发布

- **确定服务和运营事实。** 核实提供者与联系渠道、赞助与服务持续安排、基础设施主体和所在地、日志及备份的实际保留和删除。验证账号资料请求、撤销与终止、安全事件处理和供应商责任。按日志、备份、收据、删除标记分别核对保留期限，确认恢复旧备份会重施删除。法律审查以实际服务地域和处理链为依据，覆盖跨境、未成年人、请求响应、通知及取回期限。[事实依据](cloud-sync-agreement/facts-and-legal-review.md)
- **审批正式告知和接受流程。** 确认正文、摘要、语言、版本、生效日期、再次确认条件及拒绝后的退出路径。若需要接受记录，明确主体、字段、保留期限和失败处理。现有客户端本地范围确认与正式条款接受分别处理。[协议草案](cloud-sync-agreement/agreement-draft.zh-CN.md)
- **完成真实账号和双设备验收。** 验证 GitHub 授权、首启与预览、双设备合并、改密未知结果、退出及在途请求、远端删除后旧设备行为、凭据库失败和进程中断恢复。服务端和客户端分别提供各自的部署和运行证据。[同步架构](development/cloud-sync.md)
