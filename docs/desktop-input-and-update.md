# 桌面实时输入与更新源

## 文字插入与实时原文

macOS 保留录音结束后的自动文字插入，以及胶囊中的实时原文显示；不再提供“实时原文显示在输入框”的实验选项。输入框实时写入曾出现在内部预览构建中，并未包含在已发布的 Beta.4 中。本轮撤下该预览实验，历史预览保存的开启状态也不会启动它，避免普通听写或已完成的流式输出被错误转入复制兜底。胶囊原文显示与向目标输入框写入是两个独立功能。

Windows 的“实时原文显示在输入框”位于：设置 → 高级功能 → 文字插入。该选项继续使用 Windows TSF 插入管线，选项名称不附带操作系统后缀。

macOS 自动插入仍依赖有效输入目标、辅助功能授权和编辑器能力。目标定位直接查询已捕获的前台应用，并在写入前复核焦点所属应用，避免系统级 AX 焦点查询失败或焦点变化造成错误写入。不能确认安全目标或插入失败时保留可复制结果。原生测试夹具与用户在预览版中的验证不代表所有第三方编辑器均已验收。

macOS 辅助功能设置提供带应用图标的浮动引导，帮助用户将应用拖到系统授权列表并启用权限；其他系统不显示这项 macOS 专属引导。

## 更新选择

桌面检查同时请求阿里云滚动清单与 GitHub Release 元数据。GitHub 可达时以该渠道的已发布 GitHub 版本为准，Beta 与 Stable 分开；GitHub 匿名 API 被限流或失败时，在同一总超时预算内尝试官方公开发布 feed 和资源页；两条 GitHub 路径均不可用、超时或请求失败时使用阿里云结果。

同版本并发读取两条安装包链路的最多 64 KiB，用首字节延迟与传输速率比较。阿里云延迟不超过 GitHub 的 120%，且速率不低于其 80% 时视为接近，优先阿里云；GitHub 明显更快或探测无法确认阿里云优势时使用 GitHub。判断使用实际网络测量，不读取用户位置。探测上限 4 秒，不预下载整包。

GitHub 版本从安装包签名的 trusted comment 读取并核对所属 tag，保留 build metadata。版本元数据仍须由 Tauri 的安装包签名校验确认；没有签名版本或版本不匹配不能静默接受。桌面与 Android 使用各自的安装流程和架构选择。

## Android 双源更新

Android 在同一次检查中并发读取 GitHub 官方 Release 与当前渠道的 CDN 更新清单，从可验证的候选中选择更高版本；Beta 与 Stable 保持分离，并匹配设备 ABI。GitHub 已有新版而 CDN 仍为旧版时，可以直接使用 GitHub 的新版候选，不要求等待 CDN 同步，也不需要用户配置 GitHub 密钥。

下载阶段仅比较同一版本、同一架构、同一签名资产的可用链路，根据有界网络探测的延迟与传输表现选择较快来源。一个来源不可用时，只回退到该候选的其他有效链路，不能静默改为另一个版本。每个来源下载的 APK 都必须通过更新签名校验后才能进入安装流程；切换来源不绕过验签。网络探测不读取用户地理位置。

## 设置与资源生命周期

高级功能是一级分类。本地语音模型、语音增强与播放抑制、感知、启动诊断、自建同步服务器与调试工具通过独立子页进入；Windows 另有文字插入子页。感知统一容纳光标上下文与短句行为、手改学词，以及受支持桌面平台上的实验性表达格式学习，各卡片之间留出明确间距。手改学词不再占用单独的同级菜单。模型、语音增强、感知及文字插入等实验功能显示 Beta 标记；表达学习的范围和未完成项见 [感知后续工作](awareness-follow-up.md)。

退出页面即卸载控件与订阅，不为已访问的实验页面保留隐藏树。设置入场完成后暂停被遮住的主界面绘制，退场开始前恢复，保持开关动画中的底层画面连续。

界面曲面默认使用 16 px 的连续圆角；录音胶囊、实时转写胶囊及开关维持原有的胶囊形几何，纠正规则添加按钮使用 8 px。选择弹层与分段控件保留未裁切的轮廓与焦点反馈。容器用微明度色阶区分层次；暗色文本字重由 token 调整，数字统一 tabular-nums。流式新增字符保留逐字 blur，吸附位移和宽度弹簧使用过阻尼，并遵守减少动态效果。点赞按钮沿用一次性短回弹，与吸附动效分开。

WebGL 能力探测在完成后主动释放临时上下文；着色器、程序和缓冲区初始化失败也走资源释放路径。聊天头像只在进入可视区域时订阅共享动画，隐藏窗口暂停 RAF，最后一个订阅者退出后释放 GL 与画布。流式字符动画结束即撤掉 blur，不给全部字符长期设置 will-change。已移除的 Less Computer 与 Claude 控制台不再注册桌面 IPC、相关热键及后台轮询线程。

胶囊的原生点击区域使用 AppKit 的窗口本地坐标，主胶囊与每个镜像分别保存区域。区域刷新不因连续动画而反复推迟；鼠标按压期间保持既有点击归属，直到松开，避免展开语言菜单时的窗口扩容丢失鼠标事件。透明区域与原文条继续穿透；菜单的滚动区域与真实控件拥有输入，1 px 焦点代理不拥有鼠标区域。
