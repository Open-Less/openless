# 桌面实时输入与更新源

## macOS 实时原文

位置：设置 → 通用 → 文字插入 → 实时原文显示在输入框（macOS）。默认关闭。

录音时把 ASR 的最新完整原文写入开始录音时的原输入控件，替换本次听写拥有的范围。最终整理、结构化或翻译完成后，整体替换该范围。现有 OpenLess 胶囊原文条继续独立显示。

实现复用 Core 的 partial coalescing、会话终止与最终替换顺序。macOS 通过 AX 记录原控件、完整文字及选区；每次更新前检查它们是否仍匹配。切换输入框、移动光标、手动编辑、密码控件、编辑器不支持 AXSelectedText 或无法获取完整文档时停止实时替换；最终结果沿用复制兜底。取消只恢复本次替换的原始内容，不修改控件其他文字。需要辅助功能授权。编辑器兼容性必须单独做原生验证，浏览器 mock 不代表已支持某个应用。

## 更新选择

桌面检查同时请求阿里云滚动清单与 GitHub Release 元数据。GitHub 可达时以该渠道的已发布 GitHub 版本为准，Beta 与 Stable 分开；GitHub 匿名 API 被限流或失败时，在同一总超时预算内尝试官方公开发布 feed 和资源页；两条 GitHub 路径均不可用、超时或请求失败时使用阿里云结果。

同版本并发读取两条安装包链路的最多 64 KiB，用首字节延迟与传输速率比较。阿里云延迟不超过 GitHub 的 120%，且速率不低于其 80% 时视为接近，优先阿里云；GitHub 明显更快或探测无法确认阿里云优势时使用 GitHub。判断使用实际网络测量，不读取用户位置。探测上限 4 秒，不预下载整包。

GitHub 版本从安装包签名的 trusted comment 读取并核对所属 tag，保留 build metadata。版本元数据仍须由 Tauri 的安装包签名校验确认；没有签名版本或版本不匹配不能静默接受。此更新不改变 Android 独立更新路径。

## 设置与资源生命周期

高级功能是一级分类；本地语音模型、语音增强与播放抑制、光标上下文与短句行为、手改学词、启动诊断、自建同步服务器与调试工具是同级子页。模型、语音增强、光标上下文和手改学词显示 Beta 标记。退出页面即卸载控件与订阅，不为已访问的实验页面保留隐藏树。设置入场完成后暂停被遮住的主界面绘制，退场开始前恢复，保持开关动画中的底层画面连续。

界面圆角共用 16 px 的 `--ol-radius`，并采用连续曲率；支持 `corner-shape` 的引擎使用超椭圆，WebKit 使用按控件尺寸限制的曲线裁切回退。实时转写文字胶囊保持原有的胶囊形圆角。容器用微明度色阶区分层次；暗色文本字重由 token 调整，数字统一 tabular-nums。流式新增字符保留逐字 blur，吸附位移和宽度弹簧使用过阻尼，并遵守减少动态效果。点赞按钮沿用一次性短回弹，与吸附动效分开。

WebGL 能力探测在完成后主动释放临时上下文；着色器、程序和缓冲区初始化失败也走资源释放路径。聊天头像只在进入可视区域时订阅共享动画，隐藏窗口暂停 RAF，最后一个订阅者退出后释放 GL 与画布。流式字符动画结束即撤掉 blur，不给全部字符长期设置 will-change。关闭功能还会停止已删除 Agent 的后台热键轮询线程。

胶囊的原生点击区域使用 AppKit 的窗口本地坐标，主胶囊与每个镜像分别保存区域。区域刷新不因连续动画而反复推迟；鼠标按压期间保持既有点击归属，直到松开，避免展开语言菜单时的窗口扩容丢失鼠标事件。透明区域与原文条继续穿透；菜单的滚动区域与真实控件拥有输入，1 px 焦点代理不拥有鼠标区域。
