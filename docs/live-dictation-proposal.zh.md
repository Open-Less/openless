# 按手势区分实时输入与完整输出

状态：已实现首版，等待审核与 macOS 控件实测。
基线：`beta` / `6f9af895`（OpenLess 2.0.0-Beta.4）。

## 手势与输出

| 模式 | 录音期间 | 停止录音后 |
| --- | --- | --- |
| Auto 短按（不足 350 ms） | 锁存录音，不向目标应用写入中间文本；再次按键停止 | 完整结果一次性写入 |
| Auto 长按（至少 350 ms） | 支持实时 ASR、且目标控件通过能力检查时，显示 ASR 原文 | 松手停止，润色后替换本次口述范围 |
| Hold | 按住录音，在支持的目标中显示原文 | 松手停止并润色替换 |
| Toggle / DoubleClick | 保留既有录音启停语义，不写入中间正文 | 完整输出 |

使用者需选择 Auto 才能用同一个快捷键区分长短按。本改动不修改保存的快捷键模式、麦克风或识别服务。按钮、CLI、Android 与远端输入保留调用时的原有输出设置；内置结构化风格会等待完整结果校验后再输出。

实时显示依赖服务在录音期间发布 `TranscriptDelta`。稳定转写模式、批量 ASR 或只返回最终正文的服务仍在停止后完整输出；不自动换服务、不重复上传重叠音频模拟实时识别。

## 实现边界

- Core 捕获会话级 `DictationDelivery`，将热点键模式与服务的 SSE 传输方式分开。短按允许内部累计流式响应，但不向目标控件发送中间结果。
- macOS 原生桥仍按 FIFO 顺序执行异步启停。独立入口即时记录物理释放时间，避免启动握手延迟把短按误判成长按。Auto 阈值前保留最新原文快照，释放后丢弃延迟快照。
- `TranscriptAccumulator` 先应用 ASR 的 offset 修订，再把完整快照送入受保护范围更新；50 ms 合并更新。不会把全量快照当成追加片段。
- 新 `TextInsertionSession::replace_owned` 默认不支持。当前只有 macOS 的可验证 `AXTextField` / `AXTextArea` 适配器实现；Windows、Linux、Android 和不支持 AX 选区写入的控件回退完整输出。
- 本地基线通过现有 Secure Input、密码管理器、终端及字段门禁，AX 单次消息有超时，调用运行在阻塞线程。基线只用于本地保护，不作为新增 LLM 上下文上传。

## 文本所有权与取消

原文首次写入前捕获控件、空选区光标和有限长度基线（最多 20,000 UTF-16 单元）。已有选中文本时不启用实时输入。每次修订或最终替换前检查：

1. 仍聚焦同一可访问控件，仍通过安全门禁。
2. 光标在本次口述末尾、没有额外选区，全文与上次确认的本地基线相同。
3. 通过 `AXSelectedTextRange` 与 `AXSelectedText` 更新本次口述范围；选区设置后再次检查基线与选区。
4. 读取结果与光标确认送达；正确转换 UTF-16，拒绝切开 emoji 的代理对。

不发送按字符数猜测的 Backspace，也不设置控件全文 `AXValue`。发现编辑、控件切换、权限丢失或送达不确定后，停止自动写入，保留当前正文，将最终结果复制到剪贴板并走既有复制回退提示。已经尝试原生写入的会话不会再进行可能重复正文的完整粘贴。

取消会清除排队快照，并等待正在执行的原生调用结束后释放会话。已确认写入的原文不会在取消时盲目删除。

**平台限制：** macOS AX 没有跨进程原子“比较并替换”操作；这些检查无法消除用户恰在最后一次验证与 AX 写入之间操作的竞态。应在真实控件持续输入、移动光标、切换应用和取消场景中验证；本 PR 不声称提供事务级隔离。原生调用不以丢弃阻塞任务来处理超时，避免超时后的旧写入穿插到新会话。

## 输出格式

内置 `builtin.structured` 的成功润色结果在插入和历史存储前走同一校验：同级连续数字列表重新编号，移除相邻重复的同一编号（如 `2. 2.`），父项变化时重置子列表。其他风格、翻译及润色失败的原文回退不执行编号校验。

代码围栏、引用、年份、版本号、URL、字母子项和单独数字行保持原样。结构化结果不先流式写入未校验编号。清洗模型思考标签与套话时保留未发生实质清洗的原有外围空白。

报告中的 `&#x20;` 和 `2\.` 仍需对照模型原始正文与目标编辑器内容确定来源；本改动不全局解码实体或删除反斜线，也不新增默认全文日志。

## 验证与待验证

核心回归覆盖原文前缀修订、最终替换、用户编辑后的复制回退、349 ms 短按、阈值前快照缓存、取消等待正在执行的替换、完整输出、编号与历史一致性。UTF-16 范围测试覆盖中文、emoji、换行、文末插入和代理对边界。

还需维护者/使用者在真实 macOS 文本控件验证 AX 能力、实时 ASR 出字、输入法、控件自动格式化、手动编辑、焦点变化与取消。未验证平台不启用受保护替换。麦克风格式与空录音修复是独立 PR #1135。
