## 此准备 PR

仅将五处 Tauri 版本源（含 package-lock 两处）和版本契约同步为 `2.0.0+build.20261016`，不修改已经验收的语音/UI 生产逻辑，不更换用户当前 App。独立的 Core/Linux workspace Cargo.lock 不属于版本同步范围。
