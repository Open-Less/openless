# 2.0.0 main 历史集成

本候选由维护者将 `release/2.0.0-20261016`（`dbd76a4d`，生产内容为已验收 beta6 加正式版版本号）与 main 的 1.3.18 历史集成。初次 merge-tree 预演明确发现旧版本、settings、i18n、偏好写入及删除/修改冲突，未盲目采用自动合并的旧内容。

已审查 main 相对共同祖先的 22 个文件净差异：1.3.18 cask/版本、#959 的 canonical settings/偏好一致性/实验标签，以及历史 Sherpa 规划。当前 beta 的 Core facade `set_settings` 已返回 canonical preferences 并支持字段 patch，`PreferencesWriteGate` 和共享实验标题均有对应实现与回归；main 的 1.3.18 cask 两个架构 hash 已保留。旧模型页与旧规划文件依 2.0 架构决策不复活。#818/GLM 历史 commit 的 ancestry 差异没有形成 main 相对共同祖先的额外生产净差异。

因此维护者采用保留候选 tree 的 ancestry merge；merge 后 `git diff --exit-code dbd76a4d HEAD` 返回 0，证明没有引入生产逻辑、版本或依赖变化。随后只增加本文记录。main 已成为候选祖先，最终由 PR 的线性 squash 写入 main，避免强推改写历史。

此候选自身仍需完整 CI；必须先公开 beta6、合并正式版本准备 PR，再将候选合入 main。最后 main 提交的 CI、tag、资产、公开和 Homebrew 同步状态以实际交付结果为准。此记录不是已发布声明。
