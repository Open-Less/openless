# OpenLess 2.0.2-Beta.5+build.20261109-47405c88

本次为 **Beta 测试版**，比较范围为上一公开 Beta `v2.0.2-Beta.4-tauri` 至 `v2.0.2-Beta.5-tauri`。正式版更新源继续保持独立。

## 桌面界面与设置

- 调整界面曲面与嵌套圆角，保留录音胶囊、开关和小型操作按钮各自的形状。
- 修复录音方式、传统与多模态、主题、概览统计切换控件在缩放后的对齐与选中块显示。
- 修复快捷键搜索框两侧描边被裁切、背景不明显的问题，改善下拉菜单和焦点轮廓。
- 高级功能采用独立子页；感知页面的卡片保持清晰间隔，离开页面时释放控件与订阅。
- 历史列表和用量记录使用容器内滚动；改善输入法选字时的回车处理、消息跟随和跳至最新。

## 输入与胶囊

- 修复内部预览中 macOS 终稿插入错误进入手动复制兜底的回归，避免流式内容已写入后再次弹出复制窗口。
- 保留胶囊内实时原文显示。macOS 输入框内实时原文实验已从内部预览撤下；该实验未包含在公开 Beta.4 中。
- Windows 输入框内实时原文设置集中到「高级功能 → 文字插入」。
- 改善胶囊翻译语言菜单的窗口隔离、原生点击区域和多屏输入归属。
- 新增 macOS 辅助功能授权浮动引导，显示应用图标并支持拖入系统授权列表。

## 用量与模型缓存

- 侧栏设置旁新增用量入口，提供概览、服务与用途、记录三个页面。
- 已接入的文字处理路径保存服务商明确返回的 Token 报告；数量支持 K/M/B 显示，保留原始数值。
- 缓存占比按服务、渠道、模型和协议分组，区分不同接口的输入计量口径，并显示可比较报告数量。旧记录或缺失字段保持未知。
- 固定提示词规则位于动态应用、光标上下文之前，减少可避免的缓存前缀变化。
- 按实际服务地址、接口和支持的模型启用缓存标记或路由提示；多轮请求继续复用历史。缓存可用性、有效期和写入计费遵循服务商规则，实际收益以新请求返回的用量为准。

## 实验性感知与纠错

- 光标上下文、手改学词和表达格式学习集中在「高级功能 → 感知」。
- 表达格式学习默认关闭；当前学习少量全局格式倾向，在本机保存抽象证据并支持清除。
- 纠错观察过滤部分数字、否定和敏感上下文变化，建议仍由用户确认。

## 更新、性能与入口整理

- 改善 GitHub 与阿里云更新发现、限流后的备用发现，以及按网络探测选择下载来源。
- 释放闲置或失败的 WebGL、头像动画和流式字符绘制资源，减少隐藏页面持续绘制。
- 修复 Windows 选区捕获污染剪贴板历史，以及托盘退出无法结束的问题。
- 下线桌面 Less Computer / 编码 Agent 和 Claude Console，包括页面、IPC、热键和后台轮询。
- 整合 CI 并行、缓存、编译产物复用和超时优化。Linux 附包改为逐标签的明确设备验收门槛。

## 已知范围

- 用量账本尚未完整覆盖 ASR、TTS、原生 Gemini/Codex、多模态和所有重试、失败或取消路径，不能用作完整账单。
- 感知仍为实验性功能；按应用画像、黑名单和完整表达习惯系统仍在后续计划中。
- 缓存统计是输入 Token 的加权占比，不能据此承诺所有服务或所有请求达到固定命中率。
- 安装包构建与自动检查不能替代每一种编辑器、输入法、麦克风和设备上的实机行为验收。

## 分发与升级

- 发布标签为 `v2.0.2-Beta.5-tauri`，应用版本为 `2.0.2-Beta.5+build.20261109-47405c88`。
- macOS Apple Silicon 与 Intel、Windows x64、Android 各 ABI 的安装包通过同一标签构建；HarmonyOS 仓库分发包由后续流程附加。
- 本次不附加尚未完成独立设备验收的 Linux 安装包。
- Beta 用户可在「设置 → 关于与更新」加入 Beta 渠道，或从本次 GitHub Release 下载对应安装包。
- macOS 包若使用临时签名且被 Gatekeeper 拦截，可在拖入「应用程序」后按既有发行说明执行：

  ```bash
  xattr -cr /Applications/OpenLess.app
  ```
