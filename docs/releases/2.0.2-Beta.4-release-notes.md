# OpenLess 2.0.2-Beta.4+build.20261106-16d927ba

本次为 **Beta 测试版**，比较范围为上一公开 Beta **`v2.0.2-Beta.3-tauri` → `v2.0.2-Beta.4-tauri`**。正式版用户不会自动收到本版本。

## 功能更新

- **今日概览保持一屏**：桌面概览不再整页滚动，最近识别在卡片内滚动，年份热力图留在同一屏。
- **设置按任务分组**：录音与输入收成「通用」，下面是麦克风与录音、胶囊样式、文字插入、手机与远程输入。实验与扩展使用烧瓶图标，AI 与模型使用星标。
- **语音增强分成三级**：实验与扩展 → 语音增强与播放抑制 → 语音增强设置。降噪、增益、AGC 和噪声门在第三级里调整。
- **词典只从「新词」添加**：底部快速添加和场景预设卡片已去掉。新词输入和「添加」都是圆角，按下后显示「已保存」。
- **风格市场的赞会留下来**：重复打开市场不会把已赞状态清掉。搜索收成词典里那种圆形展开搜索。
- **添加渠道改成弹窗**：上下留出空隙，打开时放大并回弹一次。

## Bug 修复

- **已授权的麦克风不再被当成未授权**：已经允许麦克风时，启动不再重复请求权限。
- **Windows 胶囊关闭时保持无边框**。
- **启动诊断留在实验页卡片内**：说明和 JSON 与「诊断」标题对齐，报告在卡片内滚动，不再把后面的条目顶出窗口。

## 构建与分发改动

- 应用版本统一为 `2.0.2-Beta.4+build.20261106-16d927ba`。
- 新 Beta 标签为 `v2.0.2-Beta.4-tauri`，不会移动 `v2.0.2-Beta.3-tauri` 或稳定版标签。
- Linux 包装修订号从 149 增到 150。
- Tauri release workflow 构建 macOS ARM64/Intel、Windows x64 和 Android 四 ABI 产物；Linux egui 与 HarmonyOS 由同一标签的后续流程附加。

## 下载与升级

- Beta 用户应在设置中加入 Beta 渠道，或从 GitHub Release 下载 `v2.0.2-Beta.4-tauri` 对应平台安装包。
- macOS 14 或更新版本：Apple Silicon 使用 `aarch64.dmg`，Intel 使用 `x86_64.dmg`。本机临时安装包是 ad-hoc 签名，从 Release 安装后如被 Gatekeeper 拦截，按现有发行说明处理。
- Windows 提供 x64 NSIS 安装包；Android 提供四种 ABI 的 Beta APK。
- Stable 用户不会从 Stable updater feed 自动收到此 Beta。
