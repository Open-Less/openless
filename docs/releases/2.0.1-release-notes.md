# OpenLess 2.0.1+build.20261016

## 从 1.3.18 到 2.0：功能更新汇总

比较范围：上一个公开正式版 **`v1.3.18-tauri` → `v2.0.1-tauri`**，包含期间 Beta 累积的更新。以下先列用户功能，再列 Bug 修复、架构及构建改动。不同平台的可用功能以应用内入口为准。

贡献说明：每项下方列相关 PR 及提交者；后面的「PR 与参与者明细」分别列代码署名、审查、讨论和合并角色。部分原始 PR 已关闭，其内容通过整合提交进入版本，已注明实际路径，不冒称单独合并。整合 PR 的参与者代表整份 PR 的记录，不等同于每一个子功能的独立作者。

### 一、选区助手、语音编辑与速记

- **选区助手**：将选区润色和语音指令整合到同一入口。选中文字后，可直接润色，也可口述要求来提问、修改选区；没有选区但光标在输入框时，可使用「帮我写」生成内容。支持自动判断提问或编辑意图，并选择直接替换或预览确认。

  - **PR 与贡献**：PR [#995](https://github.com/Open-Less/openless/pull/995)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）；PR [#1077](https://github.com/Open-Less/openless/pull/1077)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）；来源 PR [#1116](https://github.com/Open-Less/openless/pull/1116)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）；PR [#1126](https://github.com/Open-Less/openless/pull/1126)（提交：[@appergb](https://github.com/appergb)）。 整合路径：#1116：经 #1126 整合。 [参与明细](#pr-995)（按 PR 编号索引）。

- **多轮语音编辑**：先口述草稿或读取目标文本，再连续说出修改要求。面板展示草稿、当前预览和每轮指令，确认后写回原输入框。

  - **PR 与贡献**：PR [#1152](https://github.com/Open-Less/openless/pull/1152)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）。 [参与明细](#pr-1152)（按 PR 编号索引）。

- **速记**：新增独立速记页面与快捷键，录音长期保留，可回放、导出、重新转录和重新润色。

  - **PR 与贡献**：来源 PR [#1087](https://github.com/Open-Less/openless/pull/1087)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）。 整合路径：#1087：经 Beta2 提交 16c3f841 整合。 [参与明细](#pr-1087)（按 PR 编号索引）。

- **历史阅读与导出**：支持展开识别原文，并设置转写文件的固定导出位置。

  - **PR 与贡献**：来源 PR [#1087](https://github.com/Open-Less/openless/pull/1087)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）；PR [#1197](https://github.com/Open-Less/openless/pull/1197)（提交：[@appergb](https://github.com/appergb)）。 整合路径：#1087：经 Beta2 提交 16c3f841 整合。 [参与明细](#pr-1087)（按 PR 编号索引）。

### 二、录音与文字输入

- **轻量麦克风增强**：提供本机麦克风的轻量降噪、增益和软限幅，默认关闭，可按需启用；不包含回声消除。

  - **PR 与贡献**：PR [#1194](https://github.com/Open-Less/openless/pull/1194)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）。 [参与明细](#pr-1194)（按 PR 编号索引）。

- **低延迟录音**：可保持麦克风就绪，并在内存中保留最多 500 毫秒预录音频。开启后系统麦克风指示灯会持续亮起，确认录音前不保存或上传音频。

  - **PR 与贡献**：PR [#1176](https://github.com/Open-Less/openless/pull/1176)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）。 [参与明细](#pr-1176)（按 PR 编号索引）。

- **稳定模式**：可选择「先录音、后识别」，录音期间不连接 ASR，停止后提交整段音频，适合录音期间网络不稳定的场景。

  - **PR 与贡献**：PR [#1082](https://github.com/Open-Less/openless/pull/1082)（提交：[@H-Chris233](https://github.com/H-Chris233)）。 [参与明细](#pr-1082)（按 PR 编号索引）。

- **胶囊流式原文**：可在录音胶囊中查看识别原文并调整原文字号；新增 Typeless 传统胶囊样式。实时显示取决于所选识别服务是否支持流式输出。

  - **PR 与贡献**：来源 PR [#1094](https://github.com/Open-Less/openless/pull/1094)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）；PR [#1158](https://github.com/Open-Less/openless/pull/1158)（提交：[@H-Chris233](https://github.com/H-Chris233)）；PR [#1197](https://github.com/Open-Less/openless/pull/1197)（提交：[@appergb](https://github.com/appergb)）。 整合路径：#1094：经 Beta2 提交 16c3f841 整合。 [参与明细](#pr-1094)（按 PR 编号索引）。

- **短句跳过润色**：可设置字数阈值，短句直接输出识别原文，不再调用文字润色模型；翻译不受此设置影响。

  - **PR 与贡献**：PR [#1185](https://github.com/Open-Less/openless/pull/1185)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）。 [参与明细](#pr-1185)（按 PR 编号索引）。

- **光标上下文扩展**：原有 macOS 能力扩展至 Windows，以及 Android 原生输入法。开启后，可让润色参考光标附近文字，辅助判断专有名词、同音词和指代；使用云端模型时，这段上下文会随请求发送。

  - **PR 与贡献**：PR [#1137](https://github.com/Open-Less/openless/pull/1137)（提交：[@DepengWang](https://github.com/DepengWang)）；PR [#1133](https://github.com/Open-Less/openless/pull/1133)（提交：[@DepengWang](https://github.com/DepengWang)）。 [参与明细](#pr-1137)（按 PR 编号索引）。

- **macOS 终端换行模式**：新增自动判断与 Line Feed 选项，可按终端和普通应用选择不同换行方式。

  - **PR 与贡献**：PR [#988](https://github.com/Open-Less/openless/pull/988)（提交：[@H-Chris233](https://github.com/H-Chris233)）。 [参与明细](#pr-988)（按 PR 编号索引）。

  - **PR 与贡献**：PR [#1040](https://github.com/Open-Less/openless/pull/1040)（提交：[@Eclock2000](https://github.com/Eclock2000)）；来源 PR [#1102](https://github.com/Open-Less/openless/pull/1102)（提交：[@leolulu](https://github.com/leolulu)）；PR [#1111](https://github.com/Open-Less/openless/pull/1111)（提交：[@appergb](https://github.com/appergb)）；PR [#1113](https://github.com/Open-Less/openless/pull/1113)（提交：[@HKLHaoBin](https://github.com/HKLHaoBin)）；PR [#1208](https://github.com/Open-Less/openless/pull/1208)（提交：[@appergb](https://github.com/appergb)）。 整合路径：#1102：经 #1111 整合。 [参与明细](#pr-1040)（按 PR 编号索引）。

### 三、加密云同步与数据管理

- **加密云同步**：在「设置 → 权限与数据」中开启，通过 GitHub 账号或 Token 在设备间同步，支持 Android。应用偏好、服务配置及 API 凭据、词典、纠正规则、风格包与图标、文本历史等先在本机加密，再上传。

  - **PR 与贡献**：PR [#1053](https://github.com/Open-Less/openless/pull/1053)（提交：[@appergb](https://github.com/appergb)）；PR [#1111](https://github.com/Open-Less/openless/pull/1111)（提交：[@appergb](https://github.com/appergb)）；PR [#1133](https://github.com/Open-Less/openless/pull/1133)（提交：[@DepengWang](https://github.com/DepengWang)）。 [参与明细](#pr-1053)（按 PR 编号索引）。

- **云端恢复与备份管理**：支持恢复前审阅、合并或替换、逐项选择冲突版本、锁定当前设备、更改同步密码，以及单独删除云端备份。原始录音、视频、模型权重和 OAuth 登录态不进入同步备份。

  - **PR 与贡献**：PR [#1111](https://github.com/Open-Less/openless/pull/1111)（提交：[@appergb](https://github.com/appergb)）；PR [#1133](https://github.com/Open-Less/openless/pull/1133)（提交：[@DepengWang](https://github.com/DepengWang)）；PR [#1138](https://github.com/Open-Less/openless/pull/1138)（提交：[@DepengWang](https://github.com/DepengWang)）。 [参与明细](#pr-1111)（按 PR 编号索引）。

### 四、本地模型与 AI 服务

- **实验性本地语音模型**：macOS 在「实验与扩展」中按需下载、启用和管理：
  - **SenseVoice Small**：普通话、粤语、英语、日语、韩语，本地 CPU 推理。
  - **TextStream**：多语种本地流式识别，提供实时草稿与确认文本；需要 Apple Silicon、macOS 14 及以上。录音期间也可供本机应用订阅转写流。
  - **Embedding Gemma**：英语语音转文字、Core ML 推理；需要 Apple Silicon、macOS 15 及以上，仍属实验性识别能力。

  - **PR 与贡献**：PR [#1197](https://github.com/Open-Less/openless/pull/1197)（提交：[@appergb](https://github.com/appergb)）；PR [#1207](https://github.com/Open-Less/openless/pull/1207)（提交：[@appergb](https://github.com/appergb)）。 [参与明细](#pr-1197)（按 PR 编号索引）。

## 下载与升级

- **macOS**：要求 macOS 14 Sonoma 或更新版本；Apple Silicon 选 `aarch64.dmg`，Intel 选 `x64.dmg`。当前使用 ad-hoc 签名、未做 Apple 公证。拖入 Applications 后，按现有分发方式执行：

  ```sh
  xattr -cr /Applications/OpenLess.app
  ```

- **Windows**：提供 x64 NSIS 和 MSI 安装包，未做发布者证书签名。
- **Android**：提供 arm64-v8a、armeabi-v7a、x86、x86_64 签名 APK，按设备选择。
- **Linux**：本次发布页不附带 Linux 安装包。
- 本页为 Stable 正式版；如需 Beta，可前往 [Beta7 发布页](https://github.com/Open-Less/openless/releases/tag/v2.0.0-Beta.7-tauri)。
