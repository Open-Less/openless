# OpenLess 2.0.2-Beta.1+build.20261017

本次为 **Beta 测试版**，不替换当前正式版 2.0.1。比较范围：上一公开 Beta **`v2.0.0-Beta.7-tauri` → `v2.0.2-Beta.1-tauri`**，包含期间正式版的打包改进及本轮胶囊、本地识别更新。

## 功能更新

- **多屏胶囊可自行选择**：在「设置 → 录音与输入 → 多屏胶囊」选择「鼠标所在屏幕」或「所有屏幕显示」。支持 macOS、Windows，默认跟随鼠标；设置会保存，恢复配置后也会应用。所有屏幕模式使用额外窗口与图形资源，只有显式选择后才创建镜像。
  - PR：[ #1222](https://github.com/Open-Less/openless/pull/1222)；提交者与代码署名：[@appergb](https://github.com/appergb)。

## Bug 修复

- **模型加载时点停止迟迟不响应**：本地模型的加载与麦克风状态解耦，麦克风就绪即可录音；点击停止先释放麦克风并进入转写，不再等模型加载完才处理停止。取消后不回放已取消音频，尚未执行的加载不再启动；加载失败会明确反馈，不伪造识别成功。
  - PR：[ #1222](https://github.com/Open-Less/openless/pull/1222)；提交者与代码署名：[@appergb](https://github.com/appergb)。
- **本地语音资源占用突增**：限制 TextStream 的 MLX 空闲缓存和内存工作集指导值；SenseVoice 固定单 CPU 推理线程，避免忙闲预算变化触发整模型重载和双份驻留。本地推理仍会占用模型所需内存，CPU 预算为可协作的平均约束，不是瞬时硬限制。
  - PR：[ #1222](https://github.com/Open-Less/openless/pull/1222)；提交者与代码署名：[@appergb](https://github.com/appergb)。
- **多屏显示与切换**：默认不再在每个屏幕重复显示胶囊；选择所有屏幕后仍只使用同一识别会话。镜像不显示学习建议或落字失败卡片；卡片始终由主胶囊处理。切回单屏、隐藏胶囊或停止后，镜像隐藏并停止动画，不再接收实时胶囊帧。
  - PR：[ #1222](https://github.com/Open-Less/openless/pull/1222)；提交者与代码署名：[@appergb](https://github.com/appergb)。

## 架构改动

- **本地加载与校验生命周期**：通过宿主任务调度异步加载实验模型；TextStream 对文件身份和元数据未变的已校验权重使用进程内缓存。首次使用、文件变化或新进程仍校验完整 SHA-256，未知 worker 不会被自动覆盖。
  - PR：[ #1222](https://github.com/Open-Less/openless/pull/1222)；提交者与代码署名：[@appergb](https://github.com/appergb)。
- **有界镜像与配置契约**：两种模式使用同一原生显示策略，处理负坐标与混合 DPI；macOS 镜像采用与主胶囊一致的非激活面板。镜像窗口有限复用，避免每次录音反复创建 WebView；新配置具有旧版默认值、序列化及同步注册校验。
  - PR：[ #1222](https://github.com/Open-Less/openless/pull/1222)；提交者与代码署名：[@appergb](https://github.com/appergb)。

## 构建与分发改动

- **新 Beta 版本与回归门禁**：应用版本统一为 `2.0.2-Beta.1+build.20261017`，使用新标签，不移动旧 Beta7 或正式版标签。增加两种模式保存/加载、无效值拒绝、模式切换缓存失效，以及 macOS/Windows 设置页的 Chromium/WebKit 回归。
  - PR：[ #1222](https://github.com/Open-Less/openless/pull/1222)；提交者与代码署名：[@appergb](https://github.com/appergb)。
- **继承已公开正式版的 Windows 打包与安装验证改进**：MSI 数字版本兼容、CI Restart Manager 隔离、成功返回值 3010 处理，以及独立固定版本的安装验证工具。Beta 提供 NSIS，不提供 MSI。
  - PR：[#1206](https://github.com/Open-Less/openless/pull/1206)、[#1213](https://github.com/Open-Less/openless/pull/1213)、[#1215](https://github.com/Open-Less/openless/pull/1215)；提交者与代码署名：[@appergb](https://github.com/appergb)。这些 PR 已合入 beta，不是本轮新写的应用功能。

## 验证说明

- 本地 Core 1211 项通过，新增偏好回归 3/3；macOS 原生 583 项通过，5 项需外部模型/安装条件的测试明确跳过；浏览器 Chromium/WebKit 完整 116/116。
- 同一 ASR 源码此前以已有模型及合成语音验证：TextStream 30.46 秒样本转写相同，worker 峰值 RSS 从约 1674 MiB 降至 1341 MiB；此样本没有证明 CPU 瞬时峰值下降。SenseVoice 单线程会牺牲部分解码速度，以降低争用并避免反复重载。
- 默认单屏、显式多屏、鼠标屏幕选择、DPI、配置保存和模式切换均有回归。自动化检查不等于所有设备和真双屏交互均已验收；模型与宿主仍可能有短时资源突发，欢迎通过本 Beta 反馈实际表现。

## 下载与升级

- **macOS**：macOS 14 Sonoma 或更新版本；Apple Silicon 选 `aarch64.dmg`，Intel 选 `x64.dmg`。当前包使用 ad-hoc 签名、未做 Apple 公证；拖入 Applications 后，按现有分发方式执行：

  ```sh
  xattr -cr /Applications/OpenLess.app
  ```

- **Windows**：x64 NSIS 安装包，未做发布者证书签名。
- **Android**：四种 ABI 的签名 APK；多屏胶囊选项仅用于桌面 macOS/Windows。
- **Linux**：本次不附带 Linux 安装包。
- Beta 不推送给 Stable 更新源；[当前正式版 2.0.1](https://github.com/Open-Less/openless/releases/tag/v2.0.1-tauri)保持不变。
